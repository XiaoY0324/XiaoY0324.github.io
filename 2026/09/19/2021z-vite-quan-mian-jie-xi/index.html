vite 是什么

  • Vite (法语意为 “快速的”，发音 /vit/) 是下一代前端开发与构建工具
  • 💡 极速的服务启动 使用原生 ESM 文件，无需打包!
  • ⚡️ 轻量快速的热重载 无论应用程序大小如何，都始终极快的模块热重载（HMR）
  • 🛠️ 丰富的功能 对 TypeScript、JSX、CSS 等支持开箱即用。
  • 📦 优化的构建 可选 “多页应用” 或 “库” 模式的预配置， 使用 Rollup 构建
  • 🔩 通用的插件 在开发和构建之间共享 Rollup-superset 插件接口
  • 🔑 完全类型化的API 灵活的 API 和完整 TypeS

public 目录

public 目录官方文档
它作为静态目录，资源可以被直接访问到，并且不会被打包。

如果你有下列这些资源：

  • 不会被源码引用（例如 robots.txt）
  • 必须保持原有文件名（没有经过 hash）
  • …或者你压根不想引入该资源，只是想得到其 URL。

那么你可以将该资源放在指定的 public 目录中，它应位于你的项目根目录，该目录中的资源在开发时，该目录中的资源在开发时能直接通过 / 根路径访问到，并且打包时会被完整复制到目标目录的根目录下。

配置代理

  • server-proxy
  • 为开发服务器配置自定义代理规则
  • 期望接收一个 { key: options } 对象。如果 key 值以 ^ 开头，将会被解释为 RegExp。configure 可用于访问 proxy 实例。

vite.config.js

import { defineConfig } from 'vite' // 更友好的提示
import pluginVue from '@vitejs/plugin-vue'
import path from 'path';

export default defineConfig({
  resolve:{
    alias:{
    '@': path.resolve('src')
    }
  },
  server: {
    proxy: {
      '/api': {
        target: 'http://jsonplaceholder.typicode.com',
        changeOrigin: true,
        rewrite: (path) => path.replace(/^\/api/, '')
      }
    }
  },
  plugins: [pluginVue()]
})

我们需要去实现一个中间件 moduleRewrite 去重写路径，简单来说，就是吧 “vue” 转换为 “/@module/vue”，然后去拦截 /@module 的请求做处理。在什么时机重写呢？

如图，当请求走过静态目录拿到静态文件之后，经过 moduleRewrite 中间件时，在这里改文件导入路径。

新建 ys-vite-cli/lib/moduleRewritePLugin.js

const path = require('path');

let { parse } = require('es-module-lexer');
var MagicString = require('magic-string');
let { readBody } = require('./utils');
function serveStaticPlugin({ app, root }) {
  app.use(async (ctx, next) => {
    await next(); // 执行下一个中间件, 就是 serveStatic 中间件,
    // 执行完了以后, 响应体就已经有内容，比如访问的 main.js，ctx.body 就是 main.js 的内容
    // import {createApp} from 'vue';
    // console.log(createApp);
    if (ctx.body && ctx.response.is('js')) {
      const originalContent = await readBody(ctx.body); // 拿到原始内容
      const rewritedContent = await rewriteImports(originalContent); // 修改
      ctx.body = rewritedContent;
    }
  });
}
async function rewriteImports(source) {
  let [imports] = await parse(source); // 文件内部 import 的包信息
  if (imports.length > 0) {
    let magicString = new MagicString(source);
    for (let i = 0; i < imports.length; i++) {
      const { n, s, e } = imports[i];
      // 如果这个引入的模块名不是以 . 或 / 开头
      if (/^[^\/\.]/.test(n)) {
        // s e 永远是指向最原始的位置索引的
        magicString.overwrite(s, e, `/@modules/${n}`);
      }
    }
    return magicString.toString();
  } else {
    return source;
  }
}


module.exports = serveStaticPlugin;

新建 ys-vite-cli/lib/utils.js

const { Readable } = require('stream');
function readBody(body) {
  if (body instanceof Readable) {
    // 如果是一个流的话, 读取流中的数据转字符串
    return new Promise((resolve) => {
      let buffers = [];
      body
        .on('data', (chunk) => buffers.push(chunk))
        .on('end', () => resolve(Buffer.concat(buffers).toString()))
    });
  } else { // 如果响应体ctx.body是字符串 Buffer 或者 别的类型,直接转字符串
    return body.toString();
  }
}
exports.readBody = readBody;

let { readBody } = require('./utils');
function processPlugin({ root, app }) {
  const injection = `
    <script>
      window.process = { env:{ NODE_ENV: 'development' }};
    </script>
  `;
  app.use(async (ctx, next) => {
    await next();
    if (ctx.response.is('html')) {
      const html = await readBody(ctx.body);
      ctx.body = html.replace(/<head>/, `$&${injection}`);
    }
  });
}

@5 编译 vue 模板

其实这一步已经不属于 vite 了，vite 的主流程已经实现。

新建 ys-vite-cli/lib/vuePlugin.js

const fs = require('fs').promises;
const path = require('path');
let { parse, compileTemplate } = require('@vue/compiler-sfc');
const defaultExportRegexp = /export default/;
function vuePlugin({ app, root }) {
  app.use(async (ctx, next) => {
    if (!ctx.path.endsWith('.vue')) {
      return next();
    }
    const filePath = path.join(root, ctx.path); // ys-vite-project/src/App.vue
    const content = await fs.readFile(filePath, 'utf8'); // 获取 App.vue 的文件内容
    let { descriptor } = parse(content);
    // 如果不存在 type, 说明请求的就是 App.vue
    if (!ctx.query.type) {
      let code = '';
      if (descriptor.script) {
        let content = descriptor.script.content;
        code += content.replace(defaultExportRegexp, 'const __script=');
      }
      if (descriptor.template) {
        // 增加一个新的 import 导入另一个路径 App.vue?type-template
        const templateRequest = ctx.path + `?type=template`;
        code += `\nimport {render as __render} from ${JSON.stringify(templateRequest)}`;
        code += `\n__script.render = __render`;
      }
      ctx.type = 'js';
      code += `\nexport default __script`;
      ctx.body = code;
    } else {
      if (ctx.query.type === 'template') {
        ctx.type = 'js';
        let source = descriptor.template.content;
        const { code } = compileTemplate({ source });
        ctx.body = code;
      }
    }
  });
}
module.exports = vuePlugin;
