数据类型转换规则

注，此文中一定要关注 [Symbol.toPrimitive]，valueOf，toString 的调用顺序。

先纠正三个容易混淆的点

这篇文章讨论的是“转换规则”。下面三件事要分开看：

  1. parseInt 接收的是字符串内容。
    例如 parseInt('0027') 读到的是字符串，省略 radix 时现代 JavaScript 按十进制处理，结果是 27。
    但 0027 如果直接写在代码里，首先会被 JavaScript 当作“数字字面量”解析，不是先传给 parseInt。旧版非严格模式可能把 00 开头的数字字面量按八进制解析，所以 0027 会先得到十进制 23；现代代码不要依赖这种旧语法，写成 0o27 才明确表示八进制。

    parseInt('0027')       // 27：解析字符串，现代默认按十进制
parseInt('0027', 10)   // 27：明确按十进制
0o27                   // 23：明确的八进制数字字面量

    浏览器 Console 里看到的下面两行，关键都发生在 parseInt 调用之前。Console 常按非严格脚本执行，所以旧式 00 开头字面量仍可能按八进制解析；严格模式和 ES module 中不要写这种语法。

    0027
// 23：旧式非严格八进制数字字面量，八进制 27 = 十进制 23

parseInt(0023)
// 19：先把字面量 0023 解析为数值 19，随后等价于 parseInt(19)
// parseInt 再把 19 转成字符串 '19'，按十进制解析，仍得到 19

parseInt('0023')
// 23：这里传入的是字符串；省略 radix 时按十进制解析

0o23
// 19：现代明确的八进制字面量写法

    一句话区分：parseInt('0023') 的前导 0 是字符串内容；parseInt(0023) 的前导 0 属于调用前已经完成解析的旧式数字字面量。不要把后者说成“parseInt 默认八进制”。

  2. Symbol.toPrimitive 不是“失败后继续往下找”。
    如果对象有这个方法，转换会先调用它；它必须返回原始值。如果返回对象等非原始值，会立即抛出 TypeError。只有对象没有这个方法时，才会按当前 hint 使用 valueOf 和 toString。

    const obj = {
  [Symbol.toPrimitive]() {
    return {}
  }
}

Number(obj) // TypeError：Symbol.toPrimitive 返回的不是原始值

  3. toString()、String(value) 和隐式转换不是同一个入口。
    直接写 obj.toString() 是直接调用这个方法；String(obj) 会先执行对象转原始值的流程；obj + 1 也会执行对象转原始值，但后面还要继续判断是拼接还是数字相加。

对象转换时，hint 由什么决定？

不要把“隐式转换”理解成固定传某一个 hint。hint 由当前操作需要什么类型决定：

场景 传入的 hint 例子
先转换成原始值、再决定后续行为 default 二元 +、对象和原始值做 ==
只能按数字处理 number 一元 +、-、*、/、大小比较
明确需要字符串 string 模板字符串、String(obj)

Date 只有一个特殊点：它收到 default hint 时，会把它按 string 处理。它不是“隐式转换时总转字符串”。

const time = new Date(0)

time + 0       // 二元 + 传 default；Date 按 string 处理，结果是日期字符串拼接 "0"
+time           // 一元 + 传 number，结果是 0
time - 0        // 减法传 number，结果是 0
String(time)    // 传 string，结果是日期字符串

先按对象类型归类，再记顺序

对象需要转成原始值
│
├─ 有 Symbol.toPrimitive（例如 Date）
│  └─ 直接调用它，并传入 hint
│     ├─ 返回原始值：转换结束
│     └─ 返回对象：立刻抛 TypeError
│
└─ 没有 Symbol.toPrimitive（普通对象）
   └─ 使用后备顺序
      ├─ default：按 number 处理，valueOf → toString
      ├─ number：valueOf → toString
      └─ string：toString → valueOf
对象 default number string
普通对象 按 number：valueOf → toString valueOf → toString toString → valueOf
Date 按 string：日期字符串 时间戳数字 日期字符串

一句话记忆：普通对象把 default 当 number；Date 把 default 当 string。

把其他类型转换为 number

基本有四种规则：

  • Number(val) 显式转 number
  • 隐式转 number
  • parseInt(val, [radix])
  • parseFloat(val)

显式转换成 number

Number 显式转换数字类型有以下几种情况：

  1. 字符串转换为数字：空字符串变 0，非有效数字变 NaN，
  2. 布尔转数字： true -> 1，false -> 0
  3. null -> 0， undefined => NaN
  4. 把 Symbol 转数字： 报错 Cannot convert a Symbol value to a number
  5. 把 BigInt 转数字： 10n -> 10, 如果超过安全数字，则按照科学记数法处理，比如 Number(666666665555555556666n) -> 666666665555555500000
  6. 把对象显式转换成数字：

    1. 如果对象有 Symbol.toPrimitive，先调用它；它必须返回原始值，否则立即报错。
    2. 只有对象没有 Symbol.toPrimitive 时，才按当前 hint 调用 valueOf 和 toString。
    还没取到原始值则报错，取到基于 Number 转换成数字，返回即可。

Number({ name: 'xx' }) // NaN
// 先调用 ({ name: 'xx' })[Symbol.toPrimitive] 方法，接收一个 hint 参数，此方法不存在于普通对象上
// 再调用 ({ name: 'xx' }).valueOf 得到 { name: 'xx' }，不是原始值
// 再调用 ({ name: 'xx' }).toString 得到字符串 "[object Object]"
// Number("[object Object]");  返回 NaN

Number([10]) // 10 
// 先调用 [10][Symbol.toPrimitive] 方法，此方法不存在于数组对象上
// 再调用 [10].valueOf 得到 [10]，不是原始值
// 再调用 [10].toString 得到字符串 "10"
// Number("10");  返回 10


let time = new Date();

Number(time); // 1621757451241
// 先调用 time[Symbol.toPrimitive] 方法，发现有，就会调用该方法，传入 'number' 类型
// time[Symbol.toPrimitive]('number'); 返回 1621757451241

Number(new Number(10)) // 10
// 先调用 (new Number(10))[Symbol.toPrimitive] 方法，此方法不存在于数字对象上
// 再调用 new Number(10).valueOf 得到 10，是原始值
// Number(10);  返回 10

var obj = {
    [Symbol.toPrimitive]() {
      return '2'
    },
    valueOf() {
      console.log('valueof');
      return '10'
    },
    toString() {
      console.log('tostring');
      return '11'
    }
}

+obj // 2 相当于 Number 调用

isNaN 会使用 Number 做显式类型转换。

隐式转换成 number

原始值隐式转数字：
原始值类型的隐式转换为数字，跟 Number 行为基本一致，唯一区别在 10n + 1 会报错，而不会先把 10n 转 10 与 1 相加(这是因为 js 不允许大数与普通数字进行运算而做的特殊处理)。
把对象隐式转换成数字：
1. 如果对象有 Symbol.toPrimitive，先调用它；它必须返回原始值，否则立即报错。
2. 只有对象没有 Symbol.toPrimitive 时，才按当前 hint 调用 valueOf 和 toString。
还没取到原始值则报错，取到返回即可，不用 Number 包装。

  • 需要数值结果的数学运算，会把对象按 number hint 转成原始值，之后再参与数值计算。
  • 对象与原始值做 == 时，对象先按 default hint 转成原始值；之后是否转 number，取决于另一边的类型。
  • 等，下面再罗列这些规则。
10n == 1 // true


var obj = {
    [Symbol.toPrimitive]() {
      return false
    },
    valueOf() {
      console.log('valueof');
      return '10'
    },
    toString() {
      console.log('tostring');
      return '11'
    }
}

1 + obj //  => 1 + false => 1 + 0 = 1

let time = new Date();

time + 1 
// 二元 + 会传入 default hint。
// Date 收到 default 后按 string 处理，因此变成“日期字符串 + 1”的拼接。

通过 parseInt、parseFloat 转换成数字

这两种方法一般用于手动转换。

  • parseInt(val, [radix])
  • parseFloat(val)

    规则：val 值必须是一个字符串，如果不是则先转换成字符串，然后从字符串首位开始查找，把找到的有效数字字符最后转换成数字「如果一个有效数字都没找到，返回 NaN」;
    遇到一个非有效数字字符，不论后面是否还有有效数字字符，都不再查找了;
    两种方法的区别在于 parseFloat 可以多识别一个小数点，而且 parseInt 有第二个参数，我们下面细说;

// 小试牛刀
parseInt('10'); // 10

parseInt('10px'); // 10
Number('10px'); // NaN

parseInt('10px10'); // 10
parseInt('10.5px'); // 10
parseFloat('10.5px'); // 10.5

Number(null); // 0
parseInt(null); // -> parseInt('null') -> NaN
parseFloat(null); // NaN

一道面试题之 parseInt 的第二个参数

先来看一道经典面试题

let arr = [27.2, 0, '0013', '14px', 123];

arr = arr.map(parseInt);

console.log(arr);

parseInt 传递的第二个值是一个 radix 进制

  1. radix 不写或者写0，默认是10进制，「如果字符串是以 ‘0x’ 开始的」，那么默认是16进制的。
  2. radix 取值范围：2 ~ 36，不在这个范围内，处理的结果都是 NaN。
  3. 在传递的字符串中，从左到右，找到符合 radix 进制的值(遇到不符合的则结束查找)，把找到的值，看做 radix 进制，最后转换为 10 进制。
  4. 其他进制转 10 进制的规则(按权展开求和)，比如 2 进制的数字 010，转为 10 进制就是 0 * 2^2 + 1 * 2^1 + 0 * 2^0 = 2，所以 parseInt(‘010’, 2) 输出 2;

特殊说明，16进制输入字符串中的 A 代表 10， F 代表 15；比如 parseInt(“1FA.37”, 16) 输出 16进制的 “1FA”，转 10 进制为：1 * 16^2 + 15 * 16^1 + 10 * 16^0 = 506

抛开 parseInt 不谈，我们单独把 3 进制表示的 10.21，转成 10 进制，它的按权展开求和为 1 * 3^1 + 0 * 3^0 + 2 * 3^-1 + 1 * 3^-2 = 3 + 0 + 2 * 1/3 + 1 * 1/ 3^2 = 34/9

parseInt(27.2, 0);
// => parseInt('27.2', 10);
// => 从左到右，找符合十进制的值，直到遇见不符合 10 进制的值，所以是 '27'
// => 把 '27' 看做 10 进制，转换为 10 进制 => 27

parseInt(0, 1);
// 进制 2 ~ 36 之间 => NaN

parseInt('0013', 2);
// => parseInt('0013', 2);
// => 从左到右，找符合 2 进制的值，直到遇见不符合 2 进制的值，所以是 '001'
// => 把 '001' 看做 2 进制，转换为 10 进制, 按权展开求和
// => 0 * 2^2 + 0 * 2^1 + 1 * 2^0 = 1 

parseInt('14px', 3);
// => parseInt('14px', 3);
// => 从左到右，找符合 3 进制的值，直到遇见不符合 3 进制的值，所以是 '1'
// => 把 '1' 看做 3 进制，转换为 10 进制, 按权展开求和
// => 1 * 3^0 = 1 

parseInt(123, 4);
// => parseInt(123, 4);
// => 从左到右，找符合 4 进制的值，直到遇见不符合 4 进制的值，所以是 '123'
// => 把 '123' 看做 4 进制，转换为 10 进制, 按权展开求和
// => 1 * 4^2 + 2 * 4^1 + 3 * 4^0 = 16 + 8 + 3 = 27

所以上面面试题的最终输出结果是 [27, NaN, 1, 1, 27]

把其他类型转字符串

基本有三种规则：

  • String(val) 显式转 string
  • 隐式转 string
  • toString()方法调用

显式转字符串

  • String()

    原始值类型显式转换成字符串：基于引号包起来，BigInt 是去掉 n
    对象类型显式转换成字符串：
    1. 如果对象有 Symbol.toPrimitive，先调用它；它必须返回原始值，否则立即报错。
    2. 只有对象没有 Symbol.toPrimitive 时，才按当前 hint 调用 valueOf 和 toString。
    还没取到原始值则报错，取到原始值用 String 包装后返回。

// 注意区别
Number(10n); // 10
String(10n); // '10' 

var obj = {
    [Symbol.toPrimitive]() {
      return false
    },
    valueOf() {
      console.log('valueof');
      return '10'
    },
    toString() {
      console.log('tostring');
      return 11
    }
}

String(obj); // 'false'

var obj2 = {
    valueOf() {
      console.log('valueof');
      return '10'
    },
    toString() {
      console.log('tostring');
      return 11
    }
}

String(obj2); // '11'

隐式转字符串

原始值类型隐式转换成字符串：基于引号包起来，BigInt 是去掉 n
对象类型隐式转换成字符串：
1. 如果对象有 Symbol.toPrimitive，先调用它；它必须返回原始值，否则立即报错。
2. 只有对象没有 Symbol.toPrimitive 时，才按当前 hint 调用 valueOf 和 toString。

 var obj = {
    [Symbol.toPrimitive]() {
      return 2
    },
    valueOf() {
      console.log('valueof');
      return '10'
    },
    toString() {
      console.log('tostring');
      return 11
    }
}

obj == '2' // true
obj + 3 // 5

var obj2 = {
    valueOf() {
      console.log('valueof');
      return '10'
    },
    toString() {
      console.log('tostring');
      return 11
    }
}

obj2 == '11' // false
'a' + obj2 // 'a10'

let time = new Date();

time + "a"
// 二元 + 会传入 default hint。
// Date 收到 default 后按 string 处理，因此变成“日期字符串 + a”的拼接。

toString() 转字符串

原始值调用 toString() 会得到对应的字符串。
对象直接调用 obj.toString() 时，只执行这个方法。即使返回非原始值（对象），也把这个对象直接作为调用结果返回；不会自动回退到 valueOf。

const returnedObject = { from: 'toString' }

const obj = {
    [Symbol.toPrimitive]() {
      console.log('Symbol.toPrimitive')
      return 2
    },
    valueOf() {
      console.log('valueOf')
      return '10'
    },
    toString() {
      console.log('toString')
      return returnedObject
    }
}

console.log(obj.toString() === returnedObject)
// toString
// true
// 没有打印 Symbol.toPrimitive，也没有打印 valueOf

总结

一、先按操作归类 hint

当前操作 hint 记忆方式
二元 +、对象与原始值的 == default 还没有确定最终要做数字运算还是字符串拼接／比较
一元 +、-、*、/、大小比较 number 操作只能按数字理解
模板字符串、String(obj) string 操作明确需要字符串

Date 收到 default 时按 string 处理；普通对象则把 default 当 number。time + 0 因此是字符串拼接，而 time - 0 是数值运算，得到时间戳。

二、对象转原始值的共同流程

  1. 对象有 Symbol.toPrimitive 时先调用它；它必须返回原始值，返回对象会立即报 TypeError。
  2. 对象没有它时，普通对象按 hint 选择后备顺序：number／default 通常 valueOf → toString；string 通常 toString → valueOf。

Date 的例外要单独放在这里记：Date 自己有内置的 Symbol.toPrimitive。它收到 default hint 时，会在自己的转换逻辑里把 default 按 string 处理，再按 toString → valueOf 尝试。也就是说，上一条“对象没有它”的普通对象后备顺序不适用于 Date；Date 不是漏掉 Symbol.toPrimitive 后才碰巧先调用 toString。

const time = new Date(0)

typeof (time + 0) // 'string'：default，Date 按 string 处理
time - 0          // 0：number，Date 优先得到时间戳
  1. 后备流程中，一个方法返回对象才继续试下一个；两个方法都没有得到原始值才报错。
  2. 得到原始值后，当前运算再继续完成自己的工作。

三、显式转换

  • Number(obj)：传 number hint；拿到原始值后，再由 Number 转成 number。
  • String(obj)：传 string hint；拿到原始值后，再由 String 转成 string。
  • obj.toString()：只是直接调用这个方法；即使返回对象，也直接把该对象作为结果，不会先走 Symbol.toPrimitive，也不会自动回退到 valueOf。

数学运算符的转换规则

此类运算中，如果一方为 NaN，则结果为 NaN

  1. 一方为字符串，会将另一方也隐式转为 string 进行字符串拼接
  2. 「除了一方为字符串的字符串拼接」，都会隐式转成 number 进行运算。

    +a 或者 -a 中的符号并不是二元运算符「加法」「减法」，而是一个一元运算符，作用是将它后面的操作数转换成数字，和 Number 显式转换完全一样。

1 + 'a' // '1' + 'a' => '1a'

1 + {}  // '1[object Object] 对象隐式转数字，推导过程如下
// ({}).toPrimitive? => ({}).valueOf? => ({}).toString() => '[object Object]'

var obj = {
  toString() {
    return 1;
  }
}

1 + obj // 2
'1' + obj // '11'

var obj2 = {
  valueOf() {
    return 1;
  },
  toString() {
    return 2;
  }
}

1 + obj2 // 2
'1' + obj2 // '11'

var obj3 = {
  [Symbol.toPrimitive]() {
    return 0;
  },
  valueOf() {
    return 1;
  },
  toString() {
    return 2;
  }
}
1 + obj3 // 1
'1' + obj3 // '10'

== 的转换规则

三等号不会进行隐式转换哦

  1. null 和 undefined 互相等，各自等。
  2. NaN 不等于 NaN。
  3. 数据类型相同，不需要转换；引用类型比较的是是否为同一个对象。
  4. 如果一方是对象，先把对象转换成原始值；普通对象的 default hint 通常按 valueOf → toString。
  5. 如果转换后仍然是一方字符串，按字符串比较；其他需要转换的数字场景再转成 number。
console.log(1 == true) 
// 1 == 1

console.log('1' == true) 
// 都转数字 1 == 1

console.log('1' == 1); 
// 1 == 1

console.log([] == false); 
// 0 == 0

console.log([1, 2] == NaN); 
//  "1，2" == NaN  -> Number("1, 2") == NaN -> NaN == NaN

console.log(['1'] == true); 
// "1" == true -> Number("1") == Number(true) -> 1 == 1

console.log([] == ![]) 
// [] == false -> "" == 0 -> Number("") == 0 -> 0 == 0

console.log({} == !{}) 
// {} == false -> Number("[object Object]") == false -> NaN == 0

console.log({} == {}) 
// false 注意 当两边数据类型相同 不进行隐式转换，如果是复杂数据类型，对比的是指针

console.log([] == []) 
// false 同上

console.log([1, 2] == '1,2'); // 对象和字符串比较 对象要转字符串
// [1, 2] => '1,2' 再做对比 为 true

a == 1 && a == 2 && a == 3

var a = ?;

// 实现如下判断
if (a == 1 && a == 2 && a == 3) {
  console.log('ok');
}

因为把对象转 number，会先尝试 Symbol.toPrimitive；没有它时，普通对象通常按 valueOf → toString 的顺序寻找原始值，最后再交给 Number 转换。改写这些方法可以影响转换结果。

var a = {
  i: 0,
  [Symbol.toPrimitive]() {
    return ++this.i
  }
}

或者直接声明成数组

var arr = [1, 2, 3]

// 当然改 valueOf 方法也可以。
arr.toString = arr.shift;

或者直接劫持变量

var i = 0;

Object.defineProperty(window, 'a', {
  get() {
    return ++i;
  }
});
