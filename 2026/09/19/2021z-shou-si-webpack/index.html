什么是 HMR

Hot Module Replacement 是指当你对代码修改并保存后，webpack 将会对代码进行得新打包，并将新的模块发送到浏览器端，浏览器用新的模块替换掉旧的模块，以实现在不刷新浏览器的前提下更新页面。
相对于 live reload 刷新页面的方案，HMR 的优点在于可以保存应用的状态, 提高了开发效率

项目创建

mkdir hmr8080 // 这个项目使用官方的 HMR
mkdir hmr9000 // 这个项目使用我们的 HMR

hmr8080 配置

cd hmr9000  
npm init -y 
npm i webpack webpack-cli webpack-dev-server html-webpack-plugin -D

webpack.config.js

const path = require('path');
const HtmlWebpackPlugin = require('html-webpack-plugin');
const HotModuleReplacementPlugin = require('webpack/lib/HotModuleReplacementPlugin'); // 热更新内置插件

module.exports = {
  mode: 'development',
  entry: './src/index.js',
  output: {
    filename: '[name].js',
    path: path.resolve(__dirname, 'dist')
  },
  devServer: {
    hot: true, // 支持热更新
    port: 8080,
    static: path.resolve(__dirname, 'static') // 额外的静态文件目录，dist 默认就是静态目录
  },
  plugins: [
    new HtmlWebpackPlugin({
      template: './src/index.html',
      filename: 'index.html'
    }),
    new HotModuleReplacementPlugin(), // 可写可不写，只要 devServer.hot 为 true，这里会默认添加
  ]
}

使用 hmr

在实现 hmr 之前，我们先来看下怎么使用它。

hmr8080/src/index.js

const { module } = require('webpack/lib/RuntimeGlobals');

let render = () => {
    let title = require('./title.js');
    root.innerHTML = title;
}

render(); // 先渲染一次

if (module.hot) { // 如果有热更新，对数组内的模块进行 render 渲染
  module.hot.accept(['./title.js'], render);
}

hmr8080/src/title.js

module.exports = 'title';
