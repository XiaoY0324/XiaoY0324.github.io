prototype (原型/显式原型)

大部分函数数据类型都具备 prototype (原型/显式原型)属性，属性值本身是一个对象「浏览器会默认为其开辟一个堆内存，用来存储实例可调用的公共的属性和方法」，在浏览器默认开辟的这个堆内存中「原型对象」有一个 construcor (构造函数/构造器) 属性，属性值是当前函数/类本身。

有些写法声明的函数是不具备 prototype 属性的，所以也不具备 prototype 上提供的 constructor，所以不能被 new 调用。

  1. 箭头函数
  2. 对象内部 es6 方式声明函数
  3. class 内部声明的原型链上的函数
// 箭头函数
const fn = () => {}

console.dir(fn);

// 对象内 es6 方式
const obj = {
    fn2() {}
}

console.dir(obj.fn2);

// class 内部声明
class Bingo {
    sum() {}
}

console.dir(Bingo.prototype.sum);

__proto__ (原型链/隐式原型)

每一个对象数据类型的值都具备一个属性 __proto__，属性值执行自己父类的原型对象 prototype

  • 对象数据类型值
    • 普通对象
    • 特殊对象：数组、正则、日期、Math、Error…
    • 函数对象
    • 构造函数.prototype
    • …

结合一道题来理解

function Fn() {
    this.x = 100;
    this.y = 200;
    this.getX = function() {
        console.log(this.x)
    }
}

Fn.prototype.getX = function() {
    console.log(this.x);
}

Fn.prototype.getY = function() {
    console.log(this.y);
}

let f1 = new Fn;
let f2 = new Fn;

// 准备好了么
console.log(f1.getX === f2.getX); // false
console.log(f1.getY === f2.getY); // true
console.log(f1.__proto__.getY === Fn.prototype.getY); // true
console.log(f1.__proto__.getX === f2.getX); // false
console.log(f1.getX === Fn.prototype.getX); // false
console.log(f1.constructor); // Fn
console.log(Fn.prototype.__proto__.constructor); // Object

f1.getX(); // 100
f1.__proto__.getX(); // undefined
f2.getY(); // 200
Fn.prototype.getY();// undefined

这个题看起来比较复杂，我们来画图理解。

爱恨纠葛的 Object 和 Function

Object 作为一个构造函数，是函数构造器(Function类)的实例。

Object instanceof Function // true

Object.__proto__ === Function.prototype // true

Function 作为一个构造函数，也是他自身的实例。
只有这样我们才可以保证，所有函数都能调用 call/apply/bind 等方法。

Function instanceof Function // true
Function.__proto__ == Function.prototype // true

Function 作为一个普通对象(实例)，它是 Object 类(对象构造器)的孙子实例

Function instanceof Object // true

Function.prototype == Function.__proto__ // true
Function.__proto__.__proto__ === Object.prototype // true

Object 作为一个普通对象(实例)， 它是 Object 对象构造器(Object类)的孙子实例

只有这样，我们才可以保证，所有的对象都能调用 Object.prototype 上的属性方法「万物皆对象」

Object instanceof Object // true

Object.__proto__ === Function.prototype // true
Object.__proto__.__proto__ === Object.prototype // true

以上需要注意的一点是：函数的原型对象是一个匿名空函数，但是所有的操作和其余的原型对象是一模一样的

Function.prototype === Object.__proto__ 

Function.prototype //  'ƒ () { [native code] }'
Object.__proto__  // 'ƒ () { [native code] }'
Function.__proto__ === Function.prototype  // 'ƒ () { [native code] }'
Function.prototype(); // 不做任何事情，但是是可以执行的哦

测验

String.__proto__ === Function.__proto__ // true
String.__proto__.__proto__ === Object.prototype // true

一句话总结

所有的类都是函数，所以都是 Function 的一个实例

所有的实例都是对象，所以都是 Object 的实例
